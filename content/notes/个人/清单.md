#### autoHotkey
【changeKeys.ahk】：
```
; 适用于 v2.0

LAlt::LCtrl

Capslock::BackSpace

+Capslock::Delete

; ctrl+backspace=ctrl+a+backspace
^Capslock:: Send "^{a}+{backspace}"

^left::Home
^right::end

*Esc::Tab

*Tab::Enter

; 禁用win弹出win菜单
~LWin::Send "{vkE8}"

; F1切换中英文输入法
F1:: Send "^{Space}"

F2::Esc

F3::Capslock
```
